# mcp-1c77-explorer

**mcp-1c77-explorer** — универсальный MCP-сервер, REST API и веб-браузер метаданных для анализа конфигураций **1С:Предприятие 7.7**.

Проект объединяет функции глубокого парсинга метаданных, поддержка двух протоколов MCP (Stdio и HTTP/SSE), полноценный REST API, а также интерактивный веб-интерфейс (Metadata Explorer) и CLI-утилиту.

---

## 🌟 Что сделано и основные особенности

1. **Единый пакет `mcp-1c77-explorer` (v0.3.0)**:
   - Полное слияние возможностей базовой версии и усовершенствованного форка.
   - Поддержка двух режимов работы транспортного слоя MCP: **Stdio** (для локальных CLI/IDE) и **Streamable HTTP / SSE** (для web-клиентов и Antigravity).

2. **Расширенный набор MCP-инструментов (19 инструментов)**:
   - Включает все 15 базовых инструментов работы с метаданными и модулями.
   - Добавлены 4 новых инструмента: экспорт всей конфигурации в JSON, экспорт отдельного объекта, поиск прямых зависимостей объекта и поиск обратных зависимостей («кто использует»).

3. **Интерактивный Web Explorer (`/explorer`)**:
   - Полноценный визуальный браузер метаданных 1С 7.7.
   - **Группированное отображение**: выводит наглядные секции по всем 9 категориям объектов (Справочники, Документы, Регистры, Перечисления, Константы, Отчёты/Обработки, Журналы, Виды расчётов, План счетов).
   - **Адаптивный дизайн и авто-перенос**: аккуратное отображение длинных неразрывных идентификаторов 1С в карточках без наложения текста.
   - **Модальные окна с деталями**: быстрый просмотр структуры объекта, исходного кода модуля, описания формы, списка используемых объектов и связанных элементов.

4. **REST API (`/api/*`)**:
   - Набор HTTP endpoints с поддержкой CORS для интеграции с внешними приложениями.
   - Полная нормализация названий типов объектов и обработка параметров.

5. **Python SDK и CLI-утилита**:
   - Клиентский модуль `MetadataClient` в `client.py`.
   - Консольная утилита `mcp-1c77-cli` для работы с метаданными из терминала.

## 🚀 Использование

### 1. Запуск сервера

```bash
# HTTP-сервер (веб-интерфейсы + REST API + SSE MCP)
python -m mcp_1c77

# Запуск в режиме Stdio MCP
python -m mcp_1c77 --stdio
```

По умолчанию HTTP-сервер запускается на `http://localhost:8080`.

### 2. Веб-интерфейсы

- **`http://localhost:8080/`** — Страница загрузки и перезагрузки файла конфигурации `1Cv7.MD`.
- **`http://localhost:8080/explorer`** — Интерактивный Metadata Explorer (просмотр и поиск метаданных, модулей и зависимостей).
- **`http://localhost:8080/api`** — Корень REST API.

## 🔌 Интеграция с MCP-клиентами

### Claude Code / OpenCode / Antigravity (SSE / HTTP)

В конфигурацию MCP-клиента (`mcp_config.json` или через CLI):

```json
{
  "mcpServers": {
    "1c77-metadata": {
      "url": "http://localhost:8080/sse"
    }
  }
}
```

Или через CLI Claude:
```bash
claude mcp add --transport sse 1c77-metadata http://localhost:8080/sse
```

### Stdio режим

```json
{
  "mcpServers": {
    "1c77-metadata": {
      "command": "python",
      "args": ["-m", "mcp_1c77", "--stdio"]
    }
  }
}
```

## 🧰 Полный список MCP-инструментов (19)

| Инструмент | Описание |
|------------|----------|
| `reload_configuration` | Перезагрузить конфигурацию или загрузить другой файл |
| `list_objects` | Список объектов метаданных с возможностью фильтрации по типу |
| `get_object` | Детальная информация об объекте (реквизиты, табличные части) |
| `get_module` | Исходный код модуля объекта (с поддержкой диапазонов строк) |
| `get_form` | Описание формы объекта |
| `get_global_module` | Исходный код глобального модуля конфигурации |
| `list_modules` | Список всех модулей конфигурации |
| `search_in_modules` | Полнотекстовый поиск по модулям с контекстом совпадений |
| `search` | Поиск объектов по имени, синониму или комментарию |
| `get_configuration_info` | Общая информация о конфигурации и количестве объектов |
| `validate_field_path` | Проверить валидность пути к реквизиту (`Товар.Артикул`) |
| `validate_query` | Проверить пути реквизитов в тексте запроса или кода |
| `search_field` | Найти все объекты, содержащие реквизит с заданным именем |
| `get_objects_batch` | Пакетное получение метаданных нескольких объектов |
| `resolve_id` | Определить тип и имя объекта по внутреннему ID |
| `export_to_json` 🆕 | Экспорт всей структуры конфигурации в JSON (строка или файл) |
| `export_object_to_json` 🆕 | Экспорт структуры конкретного объекта в JSON |
| `get_object_dependencies` 🆕 | Найти все объекты, которые использует данный объект |
| `find_dependent_objects` 🆕 | Найти все объекты, которые зависят от данного объекта |

## 🌐 REST API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api` | `GET` | Информация об API и список доступных маршрутов |
| `/api/status` | `GET` | Статус загруженной конфигурации и счетчики объектов |
| `/api/objects` | `GET` | Список объектов (с поддержкой фильтра `?type=...`) |
| `/api/objects/{type}/{name}` | `GET` | Подробная информация об объекте |
| `/api/objects/{type}/{name}/module` | `GET` | Исходный код модуля объекта |
| `/api/objects/{type}/{name}/form` | `GET` | Описание формы объекта |
| `/api/objects/{type}/{name}/dependencies` | `GET` | Список используемых объектов (прямые зависимости) |
| `/api/objects/{type}/{name}/dependents` | `GET` | Список зависимых объектов (кто использует) |
| `/api/search` | `GET` | Поиск по метаданным (`?q=...`) |
| `/api/export` | `GET` | Экспорт конфигурации в JSON |
| `/api/export/{type}/{name}` | `GET` | Экспорт конкретного объекта в JSON |
| `/api/reload` | `POST` | Перезагрузить файл конфигурации |

## 💻 CLI-утилита (`mcp-1c77-cli`)

Пакет поставляет консольную утилиту для быстрого обращения к метаданным:

```bash
# Проверить статус загруженной конфигурации
mcp-1c77-cli status

# Поиск объектов по имени или комментарию
mcp-1c77-cli search "Заказ"

# Получить список документов
mcp-1c77-cli list --type Документ

# Найти все объекты, использующие Регистр Продажи
mcp-1c77-cli deps Регистр Продажи

# Экспортировать конфигурацию в JSON-файл
mcp-1c77-cli export --save --output config.json
```
